# ROLE & OBJECTIVE
You are an expert full-stack developer. Upgrade and refine the language handling, city staff queue management, staff review catalog workflows, interactive assistant, and prototype guardrails for the "San Jose Permit Navigator" web application on Replit.

---

# 1. ADVANCED LANGUAGE SELECTION & SPELL-CHECK CONFIRMATION
- Language Dropdown & Custom Entry:
  - Include standard options (English, Spanish, Vietnamese, Chinese, Tagalog) and a "Something else / Not listed" option.
  - When "Something else / Not listed" is selected, present a text input field for the user to type their preferred language.
- Spell-Check & Confirmation Flow:
  - Upon submitting a custom language input, validate the input against common language names/spellings.
  - If a typo or misspelling is detected (e.g., "Sapanish" -> "Spanish", "Frensh" -> "French"), display an inline confirmation prompt:
    "Did you mean [Corrected Language]? [Confirm] / [Keep Original]"
  - Once confirmed, save the verified language preference and translate all generated UI elements, headings, card titles, instructions, and action plan summaries into that target language using the local translation engine.

# 2. ACTIVE REVIEW QUEUE & MULTI-PLAN MEMORY MANAGEMENT
In the "City Staff Portal" > "Active Review Queue" tab:
- Multi-Plan Queue (State Memory):
  - Support multiple active submitted action plans concurrently in a persistent local memory state array.
- Minimized Card / Bubble UI:
  - Display each submitted plan in the queue as a minimized, scannable "Plan Bubble/Card" showing key unique summary data:
    - Business Name / Address
    - Business Category & Modifications
    - Submission Timestamp
    - Current Review Status ("Draft — Requires Review")
- Collapsible Accordion / Drawer:
  - Allow staff to click any plan bubble to expand it at their discretion, revealing the full plan details, requirement cards, and staff review editing controls.
  - Staff can keep one or multiple plan bubbles expanded or collapsed independently.

# 3. REVIEW CATALOG & HISTORY (RE-OPEN & EDIT WORKFLOW)
In the "City Staff Portal" > "Review Catalog & History" tab:
- Organized Storage: Log all finalized staff decisions (Approved, Edited, Rejected, Overridden) with reviewer notes and timestamps.
- Reopen & Edit Action:
  - Add a "Re-open for Review" button next to each archived record in the catalog.
  - When clicked, shift the selected action plan from the "Review Catalog & History" back into the "Active Review Queue" tab, update its badge to "In Review (Re-opened)", and automatically navigate/forward the user directly to the Active Review Queue tab with that plan expanded for editing.
